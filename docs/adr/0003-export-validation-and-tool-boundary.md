# 导出前校验与工具边界

工具的确定性原则：布局由使用者控制，尺寸由画布预设约束，工具绝不静默改变原视频。FFmpeg 的 `overlay` 本身允许前景与背景尺寸不同（本机 4.4.1 实测把 80×60 叠到 320×180 成功），但本工具把尺寸匹配作为业务约束，而不是依赖滤镜的宽容度。

## 安全边距

预设初始值（工具的保守值，非平台官方强制规范）：

| 平台预设 | 画布 | 左右 | 顶部 | 底部 |
| --- | --- | --- | --- | --- |
| 抖音竖屏 | 1080×1920 | 64 px | 160 px | 240 px |
| B 站横屏 | 1920×1080 | 64 px | 80 px | 120 px |

自定义分辨率按 `min(W,H) / 1080` 缩放全部边距。

硬约束在布局引擎层实现，不只在 UI 层：网格原点为画布左上角 `(0,0)`，**可放置格位范围仅限安全区**（网格线仍铺满整张画布，见 ADR 0002），边距不参与格位取整；组件超出安全区禁止拖入，尺寸变化导致越界禁止提交，自动布局不得突破安全区，导出前再次全量校验。校验对象是整个组件边界矩形，不能只查左上角。

## 尺寸校验

| 场景 | 行为 |
| --- | --- |
| 源视频与目标画布一致 | 允许 |
| 源视频与目标画布不一致 | 拒绝导出 |
| 使用者明确选择外部预处理后的视频 | 允许重新校验 |
| HUD 帧与目标画布不一致 | 拒绝导出 |

工具不负责 scale / crop / pad。分辨率一致不等于画幅一致（1920×1080 与 1080×1920 像素总数相同），校验必须分别比较 width、height、SAR、DAR，并检查旋转元数据；手机拍摄素材的旋转标记不能只依赖容器报告的宽高。

## 导出流程

读取源视频分辨率 → 校验画布预设 → 校验 HUD 帧尺寸 → 全量检查组件越界 → 检查字体与资源 → 启动 FFmpeg 合成。任一步失败都拒绝导出，并明确报告实际值与期望值。
