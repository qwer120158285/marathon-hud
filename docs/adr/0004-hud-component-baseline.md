# HUD 组件清单基线

组件清单冻结为四类产品分类；功率、海拔、Lap 刻度作为对应类别下的可选子组件。以后新增跑步指标不需要改动顶层架构。

## 清单

| 类别 | 组件 | 默认状态 |
| --- | --- | --- |
| 路线 | GPS 路线轨迹 | 可配置 |
| 进度 | 距离进度条、公里刻度 | 进度条开启，Lap 刻度关闭 |
| 指标 | PACE、HR、CAD | 默认开启 |
| 天气 | 天气信息组件 | 有数据且启用时显示 |

数据卡默认三行 PACE / HR / CAD，按实际可用指标自动调整布局；缺值不显示该指标，不填占位数字。GCT 当前版本不绘制、不留空行、不填 0。

## 绘制判据

`shouldRender = configEnabled && dataAvailable`。组件配置与数据可用性分离，避免使用者开启功率但输入文件没有功率数据时出现假值。

功率、海拔、Lap 刻度默认关闭；功率与海拔开启后作为数据卡附加行，Lap 刻度开启后在进度条增加公里刻度。海拔取当前时间点对应的值，Lap 刻度以真实 Lap 数据为准，Lap 不完整时不自动伪造公里分段。样本统计值（例如当前文件的 337 W、海拔 18.8–26.2 m）只是该活动的事实，不得写为组件默认值。

## 排除项

不纳入当前版本：GCT 指标、字幕条、右上角水印、缺失数据的占位数字、自动生成的虚假 Lap 刻度。
